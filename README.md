# Location-based Call Management - Android Sample

This repository will contain a minimal Android (Java) sample implementing location-based call management features:

- Foreground location monitoring (FusedLocationProvider)
- Safe-zone definition (center + radius)
- Distance calculation utility
- CallScreeningService skeleton (block or allow calls based on safe-zone + whitelist)
- Whitelist storage and basic manager

This initial commit creates the project scaffold and a sample branch with the starter code.
